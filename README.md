This is a study on polarization statistics as a function of Alfvénic Mach number. 
We test a series of geometric templates (uniform, wavy, helical, and hourglass) for a series of turbulence models (random, kolmogorov, and Goldreich & Sridhar 1995)
Density and temperature are ignored/assumed constant throughout.

All geometries and models are found in the magnetic_fields.py script. 
Plotting is in plotting_functions.py.

You can run the models with the Jupyter Notebook analysis.ipynb.

A more detailed explanation of the model and results can be found in the paper: https://arxiv.org/abs/2609.15925
